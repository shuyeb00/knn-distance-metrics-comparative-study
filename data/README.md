# Data

The experiments use public benchmark datasets accessed through `scikit-learn`.

The datasets used by the study are:

- Iris
- Wine
- Breast Cancer Wisconsin
- LFW People
- Olivetti Faces

The datasets are **not stored or redistributed in this repository**. The supplied research notebook retrieves the required datasets programmatically through scikit-learn.

Users should consult the respective dataset/provider terms before redistributing or using the datasets for other purposes.
